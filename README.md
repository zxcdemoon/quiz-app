# AuraQuiz — Test Studio Pro

**v5.0** — интеллектуальная платформа для создания и прохождения тестов.
Всё в одном HTML-файле, работает офлайн (после первой загрузки), без серверов и регистрации.

## 🚀 Демо

▶ **[Открыть приложение](https://ZXCDEMOON.github.io/quiz-app/)**

## ✨ Возможности

### Библиотека и редактор тестов
- 6 типов вопросов: **один ответ**, **несколько**, **правда/ложь**, **текст**, **соответствие**, **сортировка**
- **Drag & Drop** вопросов и вариантов (за иконку `⋮⋮`)
- **Undo / Redo** — `Ctrl+Z` / `Ctrl+Y` (не менее 30 шагов истории)
- **Markdown** и **KaTeX-формулы** в вопросах
- **Картинки** (загрузка до 300 КБ или **AI-генерация** через Pollinations Image)
- **Объяснения** к правильным ответам
- **AI-помощник** для каждого вопроса: переформулировать, усложнить, упростить, добавить объяснение
- **AI-перевод** всего теста на английский
- **Автосохранение черновика** в `localStorage`
- **Импорт/экспорт JSON** и **CSV**

### Прохождение
- **Режим «Тест»** — классический с вариантами
- **Режим «Флеш-карточки»** — показ вопроса → раскрытие ответа → «знал / не знал»
- **Перемешивание** вопросов и вариантов
- **Случайная выборка** N из M
- **Таймер на тест** и **Спринт-режим** (секунды на каждый вопрос)
- **Озвучка вопроса** (TTS через `SpeechSynthesis`)
- **AI-подсказка** во время ответа (не раскрывает ответ)
- **Флаг «не уверен»** — отметка спорного ответа
- **Серия «правильно подряд»** 🔥
- Автосохранение незаконченной попытки

### Результаты
- **Процент, статистика, график** последних 10 попыток (SVG)
- **Слабые вопросы** — топ-5 по провалам
- **Сертификат** — при результате ≥80% (генерация PNG через `html2canvas`)
- **Разбор ответов** с объяснениями
- **Экспорт в CSV** и **печать отчёта** (PDF через браузер)
- **AI-анализ ошибок** — создаёт «закрепляющий» тест по слабым темам

### AI-генерация
- **3 бесплатных провайдера**: Pollinations, OVHcloud, Hack Club (без ключа)
- **Генерация по теме** — обычный режим
- **Генерация по тексту** — вставьте статью/конспект, AI составит тест
- **Кастомный промпт** — «с юмором», «для детей 10 лет», «со сложными формулами»
- **Подсказки во время теста**
- **Своя модель** — через URL прокси (Cloudflare Worker + Gemini)

### UX и дизайн
- **Glassmorphism** — матовое стекло поверх пастельного фона (`bg.jpg`)
- **Тёмная / светлая тема**
- **Крупный шрифт** и **плотность интерфейса**
- **Zen-режим** — скрывает сайдбар (`Ctrl+Shift+Z`)
- **Звуковые эффекты** (клик, правильно, неправильно, завершение) — генерируются через Web Audio API, **без внешних файлов**, отключаются в настройках
- **Хоткеи**: `N` новый, `A` AI, `/` поиск, `Ctrl+Z`/`Ctrl+Y` в редакторе
- **PWA** — устанавливается на телефон/десктоп как приложение

## 🛠 Установка

1. Скачайте `index.html`
2. Опционально: положите **`bg.jpg`** (ваша фоновая картинка) рядом с файлом
3. Откройте `index.html` в браузере

Всё работает локально. AI-функции требуют интернета.

## 📱 Полноценная PWA (опционально)

Для полного офлайн-режима и установки как приложения добавьте **`sw.js`** рядом с `index.html`:

```js
// sw.js
const CACHE = 'auraquiz-v5';
const ASSETS = [
  './',
  './index.html',
  './bg.jpg',
  'https://fonts.googleapis.com/css2?family=Manrope:wght@400;500;600;700;800&family=JetBrains+Mono:wght@400;700&display=swap',
  'https://cdn.jsdelivr.net/npm/katex@0.16.9/dist/katex.min.css',
  'https://cdn.jsdelivr.net/npm/katex@0.16.9/dist/katex.min.js'
];

self.addEventListener('install', e => {
  e.waitUntil(caches.open(CACHE).then(c => c.addAll(ASSETS).catch(() => {})));
  self.skipWaiting();
});

self.addEventListener('activate', e => {
  e.waitUntil(caches.keys().then(keys => Promise.all(
    keys.filter(k => k !== CACHE).map(k => caches.delete(k))
  )));
  self.clients.claim();
});

self.addEventListener('fetch', e => {
  if (e.request.method !== 'GET') return;
  if (e.request.url.includes('api') || e.request.url.includes('pollinations')) return;
  e.respondWith(
    caches.match(e.request).then(r => r || fetch(e.request).then(res => {
      const clone = res.clone();
      caches.open(CACHE).then(c => c.put(e.request, clone));
      return res;
    }).catch(() => caches.match('./index.html')))
  );
});
