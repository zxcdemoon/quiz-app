# AuraQuiz v6.0

Платформа для создания и прохождения тестов с AI, геймификацией и аналитикой. **Один HTML-файл**, работает офлайн (после первой загрузки).

## 🚀 Демо
▶ **[Открыть](https://zxcdemoon.github.io/quiz-app/)**

## ✅ Что работает в v6.0

### Геймификация
- **XP и уровни** — +10 XP за правильный ответ, +50 за «отлично»
- **Стрики** — дни подряд 🔥
- **Достижения** — 10 штук с прогрессом
- **Разблокировка тем** — Retro откроется на Lv.7, Neon на Lv.5

### Библиотека тестов
- **Корзина** — удалённые тесты восстанавливаются
- **Избранное** — звёздочка на любимых
- **История изменений** — каждое редактирование записывается
- **Поиск + теги + фильтрация**

### Типы вопросов (9)
- Один ответ
- Несколько
- Правда/Ложь
- Текст (с AI-проверкой синонимов)
- **Заполнить пропуски** (`___`)
- Соответствие
- Сортировка
- **Выбор картинки**
- **Загрузка файлом** (для кода)

### Режимы прохождения (6)
- Обычный
- Флеш-карточки
- **Survival** — 1 ошибка = конец
- **Reverse** — показывается ответ, выбрать вопрос
- **Speedrun** — на время
- **Тренировка** — только слабые вопросы

### Настройки
- **7 тем**: светлая, тёмная, Academic, Terminal, Notion, Neon, Retro
- **4 шрифта**: Manrope, Inter, Playfair, Space Grotesk
- **Авто-тема** (утро/вечер)
- Крупный шрифт, звуки, AI-провайдер

### UX
- **Онбординг** — 3 шага
- **Конфетти** при ≥90%
- **Анимация пульсации** правильного/неправильного
- **Anti-cheat** — предупреждение при переключении вкладки
- **Строгий режим** — без возврата, без подсказок

### AI
- **3 провайдера**: Pollinations, OVHcloud, Hack Club
- **Кеш** — одинаковые запросы не тратят лимиты
- **Rate limiting** через кеш
- **Батч-генерация** — 5 тестов за раз
- **Тест из текста** (можно вставить текст из PDF)
- **Подсказки** во время теста

### Результаты
- Процент + статистика
- **Сертификат** при ≥80%
- **Экспорт в CSV**, PDF (через печать)
- **Копировать результат текстом**

### Прочее
- **Шаринг ссылкой** на тест и на **конкретный вопрос** (`#q=...`)
- **Ежедневный челлендж** — 5 вопросов из разных тестов
- **Заметки** к вопросам
- **Теория** перед стартом теста
- **PWA** — устанавливается на телефон

## ❌ Что НЕ входит и почему

| Фича | Почему нет | Как добавить |
|---|---|---|
| **Облачная синхронизация** | Нужен Supabase аккаунт | См. раздел ниже |
| **PIN-комнаты** | Real-time backend | См. раздел ниже |
| **Multiplayer** | WebSocket сервер | См. раздел ниже |
| **Виджет на телефон** | Только нативный код | Через Capacitor / TWA |
| **Push-уведомления** | Нужен VAPID + сервер | Через Firebase Cloud Messaging |
| **Импорт Quizlet/Kahoot** | Нет API | Копипаст текста → AI |
| **Импорт PDF напрямую** | Нет смысла — копипаст быстрее | Вставьте текст в AI-модалку |
| **MathQuill** | 100КБ CDN | Уже есть KaTeX — `$x^2$` работает |

## 🔧 Как добавить облачную синхронизацию (Supabase)

1. Зарегистрируйтесь на [supabase.com](https://supabase.com) (бесплатно)
2. Создайте проект → SQL Editor → выполните:

```sql
create table user_data (
  id uuid primary key default uuid_generate_v4(),
  user_key text unique not null,
  data jsonb,
  updated_at timestamp default now()
);
alter table user_data enable row level security;
create policy "anyone" on user_data for all using (true);
