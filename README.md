# Quiz — Test Studio Pro

Полноценный конструктор тестов, работающий **полностью в браузере**:
без сервера, без регистрации, без зависимостей. Один HTML-файл — и у вас
свой Test Studio с AI-генерацией вопросов, аналитикой и шарингом.

## 🚀 Демо

▶ **[Открыть приложение](https://ВАШ_НИК.github.io/quiz-app/)**

> Замените `ВАШ_НИК` и `quiz-app` на свои username и название репозитория.

## ✨ Возможности

### 📚 Библиотека тестов
- Создание / редактирование / удаление тестов
- **Поиск** по названию, описанию и тегам (`/` — быстрый фокус)
- **Теги** — фильтрация по чипам, клик для применения
- **Копия теста** в один клик — `⎘`
- **Экспорт одного** теста в JSON — `↓`
- **Печать** чистого бланка (`@media print`) — `🖨`
- **Шеринг через URL** — `🔗` копирует ссылку `#test=<base64>` (тест живёт в самой ссылке, без сервера)
- Хоткеи: `N` — новый, `A` — AI, `/` — поиск, `Enter` — открыть единственный найденный

### ✎ Редактор тестов
- **5 типов вопросов:**
  - `single` — один правильный ответ
  - `multi` — несколько правильных (чекбоксы)
  - `text` — ввод свободного ответа
  - `matching` — соответствие (левый/правый столбец)
  - `sort` — сортировка элементов (↑↓)
- **Markdown** в вопросах, вариантах и объяснениях: `**жирный**`, `*курсив*`, `` `код` ``
- **KaTeX-формулы:** `$x^2$` или `$$...$$`
- **Картинки** в вопросах (загрузка файла, до 300 КБ, хранится как data URL)
- **Объяснение** к каждому вопросу (показывается после прохождения)
- **Автосохранение черновика** в `localStorage` каждые 1.5 сек
- Кнопки **AI-помощи** для каждого вопроса:
  - 🤖 **Переформулировать** — яснее, сохранив смысл
  - 🔺 **Усложнить** / 🔻 **Упростить**
  - 💡 **Объяснение** — сгенерировать пояснение к правильному ответу
- **AI Перевод** всего теста на английский
- **Подтверждение выхода** с несохранёнными изменениями

### 🎯 Прохождение
- **Таймер** с предупреждением в последние 30 секунд
- **Сегментированный прогресс-бар** (каждый сегмент = вопрос)
- **Случайная выборка N из M** — из 100 вопросов взять N случайных
- **Перемешивание** вопросов и вариантов
- **Флаг «не уверен»** — отметка спорного ответа, отдельная категория в разборе
- **Счётчик серии** «правильно подряд» с подсветкой при ≥3
- **Автосохранение попытки** — закрыли вкладку, вернулись, продолжили с того же места
- Хоткеи: `←/→` навигация, `1–9` выбор варианта (для `multi` — toggle)

### 📊 Результаты и аналитика
- **4 карточки статистики**: попыток, средний %, лучший %, последний %
- **SVG-график** последних 10 попыток (без библиотек, чистый SVG)
- **Слабые вопросы** — топ-5 по количеству провалов (появляется со 2-й попытки)
- **Полный разбор** — каждый вопрос с отметками ✓/✗, вашим ответом и объяснением
- **Копировать результат текстом** — `«12 из 15 (80%) — История России»` в буфер обмена
- **Экспорт в CSV** — для сдачи преподавателю (все вопросы, ответы, статусы)
- **PDF через печать** — красиво оформленный отчёт (`window.print()`)
- **AI-анализ ошибок** — генерирует новый тест по слабым темам

### 🤖 AI-генерация
- **🤖 AI Создать** — целый тест по теме (тема, количество, сложность)
- **🤖 AI Вопросы** — дописать вопросы к текущему тесту
- **🌐 AI Перевод** — перевести тест на английский
- **🤖 AI Анализ ошибок** — после прохождения генерирует «закрепляющий» тест
- Настройки: тема, 1–20 вопросов, сложность (лёгкая/средняя/сложная/смешанная)
- **Skeleton-загрузка** при ожидании ответа AI

### ⚙ Кастомизация
- 🌙 **Тёмная тема** — полная инверсия
- 📏 **Размер шрифта**: обычный / крупный (для больших экранов)
- 📐 **Плотность**: компактно / обычно / просторно
- 🔌 **AI-прокси URL** — свой Cloudflare Worker вместо Pollinations

### 📥 Импорт / экспорт
- **Импорт JSON** — одиночный тест или массив
- **Импорт CSV** — формат `Вопрос;A;B;C;D;Правильный(1-4);Объяснение`
- **Экспорт всех** — один JSON-файл со всей библиотекой
- **Экспорт одного** — по кнопке `↓` у теста
- **Шеринг URL** — тест закодирован в хэше, работает без сервера

### 💾 Хранение
- Всё в `localStorage` браузера — тесты, попытки, черновики, настройки
- **Приватность**: ни один запрос не уходит на сервер, кроме AI-генерации
- При использовании AI-прокси — запрос идёт на ваш Worker / ваш ключ

## 🛠 Как запустить локально

Скачайте `index.html` и откройте в браузере. Сборка не требуется.

Все функции работают офлайн, кроме **AI-генерации** (нужен интернет к
`text.pollinations.ai` или вашему прокси).

## 🤖 AI: как работает

**По умолчанию — Pollinations AI:**
- Бесплатно, без ключа, без регистрации
- Публичный API в формате OpenAI
- Ограничение: ~1 запрос в 15 секунд (при высокой нагрузке — `429`)
- Задержка: 10–40 секунд на запрос

**Опционально — свой прокси** (рекомендуется для активного использования):

1. Разверните Cloudflare Worker (бесплатно до 100 000 запросов/день):
```js
export default {
  async fetch(request, env) {
    if (request.method === "OPTIONS") {
      return new Response(null, {headers: {
        "Access-Control-Allow-Origin": "*",
        "Access-Control-Allow-Methods": "POST, OPTIONS",
        "Access-Control-Allow-Headers": "Content-Type"
      }});
    }
    const body = await request.json();
    const r = await fetch(
      "https://generativelanguage.googleapis.com/v1beta/openai/chat/completions",
      {
        method: "POST",
        headers: {
          "Content-Type": "application/json",
          "Authorization": "Bearer " + env.GEMINI_KEY
        },
        body: JSON.stringify({
          model: "gemini-2.5-flash",
          messages: body.messages,
          temperature: body.temperature || 0.8
        })
      }
    );
    return new Response(r.body, {
      status: r.status,
      headers: {
        "Content-Type": "application/json",
        "Access-Control-Allow-Origin": "*"
      }
    });
  }
}
