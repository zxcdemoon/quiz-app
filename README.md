# Quiz App — тестовая оболочка с AI-генератором

Простой одностраничный конструктор тестов с вариантами ответов и генерацией
вопросов через бесплатный AI. Работает полностью в браузере — без сервера,
без регистрации, без зависимостей.

## 🚀 Демо

▶ **[Открыть приложение](https://ВАШ_НИК.github.io/quiz-app/)**

> Замените `ВАШ_НИК` и `quiz-app` на свои username и название репозитория.

## ✨ Возможности

### Тесты и вопросы
- 📚 Библиотека тестов: создание, редактирование, удаление
- ✎ Встроенный редактор вопросов и вариантов ответа
- 🔀 Перемешивание вопросов и вариантов при прохождении
- 📁 Импорт / экспорт тестов в JSON
- 💾 Автосохранение незавершённой попытки в `localStorage`

### Прохождение
- ⏱ Таймер с предупреждением в последние 30 секунд
- 📊 Прогресс-бар и счётчик вопросов
- 🔍 Полный разбор ошибок после прохождения
- ⌨️ Управление с клавиатуры (стрелки ←/→, цифры 1–9)
- 📱 Адаптивный интерфейс для мобильных

### 🤖 AI-генерация
- **🤖 AI Создать** — сгенерировать целый тест по теме
- **🤖 AI Вопросы** — дописать вопросы к текущему тесту
- Настройки: тема, количество (1–20), сложность (лёгкая/средняя/сложная/смешанная)
- Работает на **Pollinations AI** — **бесплатно, без ключа и без регистрации**
- Сгенерированный тест открывается в редакторе для проверки и правки

## 🛠 Как запустить локально

Скачайте `index.html` и откройте в браузере. Сборка не требуется.

Для работы AI-генерации нужен доступ в интернет к `text.pollinations.ai`.
Остальные функции работают полностью офлайн.

## 🤖 Как работает AI-генерация

1. Нажмите **🤖 AI Создать** (в библиотеке) или **🤖 AI Вопросы** (в редакторе).
2. Укажите тему, количество вопросов и сложность.
3. Нажмите **✨ Сгенерировать** — подождите 10–40 секунд.
4. Проверьте результат в редакторе и нажмите **💾 Сохранить тест**.

**Технические детали:**
- Используется публичный API [Pollinations AI](https://pollinations.ai) — эндпоинт `text.pollinations.ai/openai` в формате OpenAI Chat Completions.
- Никакой регистрации и API-ключей не требуется.
- Модель по умолчанию — `openai`. При желании в коде (`callPollinations`) можно переключить на `mistral`, `qwen` и другие.
- Ответ приходит в JSON, извлекается устойчиво (даже если AI обернёт его в ` ```json … ``` `).

**Возможные ограничения:**
- Сервис **публичный и бесплатный**, поэтому очередь общая. При высокой нагрузке ответ может занять до минуты.
- Повторные запросы подряд могут временно блокироваться (`429`). В этом случае — подождите 15–30 секунд.
- Если сервис перегружен, приложение покажет понятную ошибку и предложит повторить.
